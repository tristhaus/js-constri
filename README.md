# Constri in Javascript

Constri is a language to describe geometric construction in 2D. It was originally conceived by Hupfeld Software.

This a work-in-progress implementation of Constri in JS for use with e.g. smartphones. A German and English version is currently deployed at [tristhaus.github.io/js-constri](https://tristhaus.github.io/js-constri/).
